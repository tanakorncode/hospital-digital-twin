# คู่มือเจ้าหน้าที่ — Hospital Digital Twin

สำหรับเจ้าหน้าที่เคาน์เตอร์ จุดคัดกรอง ห้องตรวจ หัวหน้างาน และผู้ดูแลระบบ · ฉบับนำร่อง 2026-10

> หลักสำคัญ: ระบบช่วยงาน ไม่แทนการตัดสินใจของเจ้าหน้าที่ · ผู้ป่วยที่ไม่ใช้ LINE ใช้บริการที่เคาน์เตอร์ได้ทุกอย่าง · จอสาธารณะและข้อความ LINE ไม่มีชื่อหรือ HN

---

## 1. เริ่มต้นวัน
1. เปิดเว็บของระบบ เข้าสู่ระบบด้วยบัญชีของตัวเอง (ทุกการกระทำบันทึกในชื่อคุณ — ห้ามใช้บัญชีร่วมกัน)
2. **ติดตามคิว → ช่องบริการของฉัน** → เลือกจุดที่ประจำ (ครั้งแรกครั้งเดียว เครื่องจะจำไว้) → กด **เปิดจุดบริการ**
3. ดูป้ายบนหัวหน้าจอ: **"ผู้ป่วยจริง"** = ใช้งานจริง · ถ้าไม่มีป้ายนี้ = โหมดสาธิต (ข้อมูลจำลอง) แจ้งผู้ดูแลระบบ

## 2. เคาน์เตอร์ลงทะเบียน
**ผู้ป่วยมาหน้างาน (ไม่ได้จอง):** ปุ่ม **รับผู้ป่วยเข้าคิว** → เลือกคลินิก (หรือห้องฉุกเฉิน) → ถ้าผู้ป่วยเชื่อม LINE ไว้ ใส่ **HN** และติ๊ก "ตรวจบัตรประชาชนแล้ว" (ผู้ป่วยจะเห็นคิวในมือถือและได้แจ้งเตือน) → ถ้าเป็นคิวพิเศษ เลือก พระภิกษุ / หญิงตั้งครรภ์ / รถเข็น / ผู้พิการ / ผู้สูงอายุ → **ออกเลขคิว** → กด **แสดง QR บนบัตรคิว** ให้ผู้ป่วยสแกน หรือพิมพ์บัตรคิว

**ผู้ป่วยที่จอง/นัดไว้มาถึง:** ให้ใช้ตู้เช็กอิน หรือที่เคาน์เตอร์: **การจอง** (หรือ **นัดหมาย**) → หาด้วยรหัส BK…/AP… หรือ HN → **เช็กอิน** → ได้เลขคิว + QR
- มาก่อนเวลามาก/มาสาย: เคาน์เตอร์เช็กอินให้ได้ในวันเดียวกัน (ระบบบันทึกว่า "นอกช่วงเวลา")
- รหัสใช้ไม่ได้ (ยกเลิก/หมดอายุ/ผิดวัน): ระบบบอกเหตุผล → รับเป็นผู้ป่วยหน้างานแทน

**บัตรคิวหาย:** ในคอนโซล กดหน้าคิวผู้ป่วย (QR) → **ออก QR ใหม่** (ลิงก์เดิมและลิงก์ญาติใช้ไม่ได้ทันที)

## 3. จุดซักประวัติ / ห้องตรวจ / ห้องยา / การเงิน
ปุ่มใหญ่เปลี่ยนตามขั้น: **เรียกคิวถัดไป** → **มาแล้ว · เริ่มให้บริการ** → **เสร็จ** (คีย์ลัด Space)
- เรียกแล้วไม่มา: **เรียกซ้ำ** (R) — ครบ 3 ครั้งระบบพักคิวเป็น "ไม่มาตามเรียก" ให้
- **พักคิว** (H) เช่น ไปห้องน้ำ / ไปเจาะเลือดก่อน · **ย้าย/ส่งต่อ** (M) ไปช่องอื่นในแผนกเดียวกัน
- **ผู้ป่วยจริง: แถบ "ส่งต่อ"** ใต้เลขคิว — แพทย์/พยาบาลสั่งขั้นต่อไป: เจาะเลือด · เอกซเรย์ · ฟังผล/พบแพทย์ซ้ำ · รับยา · ชำระเงิน · ถ้าไม่สั่งอะไรต่อ กด **เสร็จ** แล้วผู้ป่วยกลับบ้าน
- รับผู้ป่วยผิดคลินิก/ซ้ำ: แถบส่งต่อ → **ยกเลิกคิว** (เลือกเหตุผล)
- ผู้ป่วยกด "ขอความช่วยเหลือ" จากมือถือ: ขึ้นแถบสีส้ม → **รับเรื่อง**

## 4. การจองคิวล่วงหน้า (ติดตามคิว → การจอง)
- **จองให้ผู้ป่วย** (ทางโทรศัพท์/เคาน์เตอร์): ตรวจบัตรประชาชนก่อน → กรอก HN → คลินิก → วัน → ช่วงเวลาที่ว่าง → ยืนยัน → **แจ้งรหัส BK…** ให้ผู้ป่วย
- **ยกเลิก**: เลือกเหตุผล · หลังเวลาปิดรับยกเลิก ต้องให้หัวหน้างานทำ
- ผู้ป่วยที่เชื่อม LINE จองเองได้ และได้ข้อความยืนยันทาง LINE

## 5. นัดแพทย์ (ติดตามคิว → นัดหมาย)
- **นัดผู้ป่วย**: HN → คลินิก → วัน → แพทย์และเวลา → ยืนยัน → **แจ้งรหัส AP…** (ผู้ป่วยที่เชื่อม LINE ได้ข้อความ และได้เตือนก่อนวันนัด 18:00)
- **เลื่อน**: เลือกเวลาใหม่ — ที่เดิมคืนเมื่อได้ที่ใหม่แล้วเท่านั้น ถ้าเวลาใหม่เต็ม นัดเดิมไม่เปลี่ยน
- **คำขอเลื่อนนัดรอพิจารณา** (กล่องสีเหลือง, มาจาก LINE): **อนุมัติ** หรือ **ไม่อนุมัติ** พร้อมเหตุผล (ผู้ป่วยได้ข้อความ)
- **ห้องตรวจของแพทย์** (หัวหน้างาน): กล่อง "ห้องตรวจของแพทย์วันนี้" — ผู้ป่วยนัดรอที่ห้องของแพทย์คนนั้น · แพทย์ย้ายห้อง เปลี่ยนที่นี่ ผู้ป่วยที่รออยู่ย้ายตาม
- **ไม่มาตามนัด**: เฉพาะหัวหน้างาน หลังเลยเวลานัด และต้องเลือกเหตุผล — ระบบไม่บันทึกเองอัตโนมัติ และการไม่เปิดอ่าน LINE ไม่ถือว่าไม่มา

## 6. เชื่อมบัญชี LINE ของผู้ป่วย (ติดตามคิว → เชื่อม LINE)
1. ผู้ป่วยเปิด LINE ของโรงพยาบาล → เมนู → **ขอรหัสเชื่อมบัญชี** → แสดง QR (หรือรหัส 8 ตัว)
2. กด **สแกน** (หรือพิมพ์รหัส) → **ตรวจบัตรประชาชน** ว่าตรงกับผู้ป่วย → กรอก HN → ติ๊ก "ตรวจบัตรแล้ว" → **ยืนยันเชื่อมบัญชี**
3. มือถือผู้ป่วยเปลี่ยนเป็น "เชื่อมบัญชีเรียบร้อย" เอง
- ผู้ป่วยเปลี่ยนโทรศัพท์: ทำซ้ำได้เลย บัญชีเดิมถูกยกเลิกอัตโนมัติ
- โทรศัพท์หาย/เชื่อมผิดคน: **ตรวจสถานะการเชื่อม** ด้วย HN → **ยกเลิกการเชื่อม** (เลือกเหตุผล)
- **ห้าม** เชื่อมให้โดยไม่ตรวจบัตร และห้ามรับรหัสผ่านทางโทรศัพท์/แชต

## 7. ตู้เช็กอิน (`/kiosk`)
ผู้ดูแลเข้าสู่ระบบที่ตู้ครั้งเดียวด้วยบัญชีสำหรับตู้ · ผู้ป่วยกด **BK** (จอง) หรือ **AP** (นัด) แล้วกดรหัส 6 ตัว หรือสแกนบาร์โค้ด → ได้เลขคิว + QR + พิมพ์บัตรคิวได้ · หน้าจอกลับหน้าแรกเองใน 45 วินาที
ปัญหาที่พบบ่อย: "เช็กอินได้ตั้งแต่ …" (มาเร็วเกิน) / "เลยเวลาเช็กอิน" → ส่งไปเคาน์เตอร์

## 8. หัวหน้างาน
- **ภาพรวมคิว**: คนรอแต่ละจุด, ย้ายคิวหลายคน, ตัวช่วยกระจายคิว
- ยกเลิกการจอง/นัด **หลังเวลาปิดรับ** (ต้องเปิดสวิตช์ "เจ้าหน้าที่แก้ไขแทนผู้ป่วย" ไว้) · บันทึก **ไม่มาตามนัด**

## 9. ผู้ดูแลระบบ (ตั้งค่า)
| หน้า | ใช้ทำอะไร |
|---|---|
| ข้อมูลผู้ป่วย | สลับ **สาธิต / ผู้ป่วยจริง** · เปิดการเชื่อมบัญชี LINE |
| การจองล่วงหน้า | เปิดระบบจอง, กติกาต่อคลินิก, สร้าง/ปิด/ยกเลิกช่วงเวลา |
| นัดแพทย์ | เปิดระบบนัด, กติกา, ตารางออกตรวจของแพทย์ (ยกเลิกตารางเมื่อแพทย์งดตรวจ) |
| การแจ้งเตือน | เปิดข้อความ LINE, ดูรายการที่ส่งไม่สำเร็จ, ส่งใหม่ |
| QR นำทาง | จุดหมาย, จุดสังเกต, พิมพ์ป้าย QR |
| LINE OA | ดูว่าตั้งค่า LINE ครบหรือยัง, ลองคุยกับบอท, ติดตั้งเมนู 6 ปุ่มใต้แชต (rich menu) |
| บันทึกการใช้งาน | ใครทำอะไรเมื่อไร (ใช้ตรวจสอบเหตุผิดปกติ) |
| การเก็บข้อมูล | ระยะเวลาเก็บแต่ละหมวดตามที่โรงพยาบาลอนุมัติ (ค่าตั้งต้น = เก็บตลอด) · ดูว่าจะลบอะไรก่อนบันทึก |
| ผู้ใช้งาน | สร้าง/ระงับบัญชี, รีเซ็ตรหัสผ่าน, **แผนกที่รับผิดชอบ** (ไม่เลือก = ทุกแผนก เช่น เวชระเบียน/บัญชีตู้เช็กอิน) |

**สำรองข้อมูล** ทุกคืนอัตโนมัติ — ตรวจว่าไฟล์ถูกคัดลอกออกนอกเครื่อง · เหตุขัดข้อง: ดู `docs/PILOT-READINESS.md` §7

## 10. เมื่อระบบใช้ไม่ได้
- หัวจอขึ้น "ออฟไลน์": ตรวจเครือข่าย · ระหว่างนั้นใช้บัตรคิวกระดาษตามขั้นตอนเดิมของโรงพยาบาล
- ทุกอย่างช้า/ผิดปกติ: แจ้งผู้ดูแลระบบ — ผู้ดูแลสลับกลับเป็นโหมดสาธิตได้ทันที (ข้อมูลจริงของวันยังอยู่)
